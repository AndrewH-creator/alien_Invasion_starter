# Pixel Space Invasion — Track 2: Custom Game Assets

## Project Overview

Pixel Space Invasion is a 2D space shooter created using Python and Pygame. This project builds upon the original Alien Invasion tutorial game.

I selected **Track 2: Custom Game Assets** to transform the original game into a retro pixel-themed space shooter with custom graphics, sound effects, animations, and an updated user interface.

## Milestone 1 — Core Player Assets & Theme

For Milestone 1, I customized the following game elements:

- **Spaceship:** Replaced the original ship with a retro pixel-style spaceship.
- **Background:** Added a custom space background.
- **Laser:** Replaced the original bullet graphic with a custom laser image.
- **Laser Sound:** Added a custom laser firing sound.
- **Game Caption:** Changed the window title to "Pixel Space Invasion - Track 2."

The game allows the player to move left and right using the arrow keys and fire lasers using the spacebar.

Features intended for later milestones, including alien fleets, scoring, HUD, and the Play button, are temporarily disabled.

## Game Controls

| Key | Action |
|---|---|
| Left Arrow | Move spaceship left |
| Right Arrow | Move spaceship right |
| Spacebar | Fire laser |
| Q | Quit game |

## Running the Game

1. Install Python.
2. Open the project in VS Code.
3. Install dependencies using `python -m pip install -r requirements.txt`.
4. Run the game using `python alien_invasion.py`.
